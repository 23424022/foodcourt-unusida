# Aplikasi Android Kantin

Pembungkus (Capacitor) untuk halaman kasir `/kantin/`. Aplikasi memuat halaman dari server yang sudah online,
jadi setiap deploy ulang otomatis memperbarui isi aplikasi tanpa membuat APK baru.
APK dibuild otomatis oleh GitHub Actions (`.github/workflows/build-kantin-apk.yml`). Lihat PANDUAN.md bagian G.
